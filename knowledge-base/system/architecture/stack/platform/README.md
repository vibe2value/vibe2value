# Platform

Where PROJECT_NAME runs: the runtime, hosting and the platform-native primitives it deploys onto, such as storage, queues or scheduling the platform provides directly. This is the layer underneath the code, not a library you bundle into it. One file per choice.

## How to add one

1. Copy [`template.md`](template.md) to `<name>.md` in this folder.
2. Fill in the sections.
3. Record the call as an ADR in [`../../../decisions/`](../../../decisions/README.md).

When a choice is added, swapped or removed, change its file and write the ADR that explains why.
