# External services

What PROJECT_NAME talks to: third-party services reached over the network at runtime, such as email, authentication, payments or analytics. Each one is a dependency you do not control and an assumption about its availability and cost. One file per choice.

## How to add one

1. Copy [`template.md`](template.md) to `<name>.md` in this folder.
2. Fill in the sections.
3. Record the call as an ADR in [`../../../decisions/`](../../../decisions/README.md).

When a choice is added, swapped or removed, change its file and write the ADR that explains why.
